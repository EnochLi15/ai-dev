# AI 晨报栏目重构提案 v0.2（2026-11-03 · 待所有者确认，未生效）

> 背景：现行栏目沿用了最初口头点名的几个方向（Agent 开发 / AI Coding / 前沿资讯 / 产品更新），实际运行两天后暴露三个问题：**① 分类不正交**（Agent 开发 × AI Coding 大量重叠，coding agent 本身就是最大的 agent 品类；Claude Code skill 生态两条都放）；**② "产品与行业"是个杂物间**（产品更新、融资、政策、快讯混装）；**③ 量太大且重复**（头条与正文重复出现，社区脉搏与已报新闻重复，30+ 条全是一个层级）。本提案只改信息架构，不动采集管线与定时任务。

## 一、设计原则

1. **一个维度切到底**：栏目 = 主题域（这条新闻"关于什么"），处理深度用"精读/速览"两层表达（这条新闻"配多少注意力"），两个维度不再混在栏目名里。
2. **一条新闻只有一个家**：禁止同一事件在两个栏目出现；头条是从全报中"提级展示"的唯一例外，但正文不重复展开。
3. **固定认知路径**：栏目顺序 = 开发者早晨的真实决策顺序——先知道出大事没有，再看能装能用什么，再看模型与思想，最后扫一眼其余。
4. **总量硬约束**：精读 ≤10 条，速览 ~15 条，5 分钟读完；进不了精读的自动降级速览，不丢但降噪。

## 二、新栏目大纲（9 节，固定顺序）

| # | 栏目 | 收什么 | 条数 | 替代旧栏目 |
|---|------|--------|------|-----------|
| 0 | **导语** | 1-2 句：今天最值得知道的一件事 + 一句话定调 | 1 | 原"头条速览"导语 |
| 1 | **头条 · 今日必看** | 全局最重要 1-3 条（跨域选拔）；每条=事实一句+为什么重要+怎么看 | 1-3 | 原"今日头条" |
| 2 | **开发者工具箱** | 一切"今天能装/能升级/能调用"的：agent 框架、SDK、终端 coding agent、skill 生态、harness、本地推理（Ollama 类） | 精读 2-4 + 快看 N | 合并原"AI Agent 开发"+"AI Coding"（两者本不正交） |
| 3 | **模型前沿** | 模型发布/评测/能力边界/💰定价与成本变化；⚠️未证实传闻集中在此节末尾"传闻区"统一管理 | 精读 2-4 + 快看 N | 原"前沿模型与研究"的模型半边 + 原"产品与行业"里的模型产品更新 |
| 4 | **研究与思想** | 论文、长文、观点（陶哲轩这类）；启发层，不含产品 | 1-3 | 原"前沿模型与研究"的研究半边 + 原"今日必读"多数内容 |
| 5 | **安全与合规** | 攻击事件、漏洞、供应链、政策/管制/出口管制——现在散落各处的 ⚠️ 全部归此 | 1-4 | **新增**（原散落在 Coding/产品行业里） |
| 6 | **商业与资本** | 钱：融资/IPO/财报/巨额支出/并购；消费级产品动态不涉及钱的也放这的"快看" | 精读 1-2 + 快看 N | 原"产品与行业"拆解后的资本半边 |
| 7 | **开源雷达** | 新爆发项目 + **已收录项目的重大异动**（版本/星标暴涨≥3×，台账制跨期去重不变） | 2-4 + 快看 | 原"GitHub 趋势榜"升级 |
| 8 | **一句话电报** | 未入正文但值得知道的一切，一行一条，按域分组；含 HN 热榜数字 | 10-15 | 原"社区脉搏"+"一句话快讯"合并降级 |
| 9 | **今日必读** | 严格 1 条全文链接 + 为什么值得 10 分钟 | 1 | 原"今日必读"（收严） |

## 三、条目格式规范（所有栏目统一）

```
**标题（动词优先，说清"发生了什么"）**（日期，[来源](链接)）
事实一句。对开发者意味着什么一句。[💰价格变化时标注]
```
- 标记系统：`⚠️` 单源未证实 · `💰` 价格/成本 · `🔥` HN≥500 分 · `🇨🇳` 国产动态（标注不加栏，保持主题域正交）
- 每条正文 ≤3 行；链接全部回源可查的纪律不变。

## 四、旧 → 新 映射与解决的问题

| 旧栏目 | 去向 | 解决的问题 |
|--------|------|-----------|
| AI Agent 开发 + AI Coding | → 开发者工具箱 | 消除最大重叠源 |
| 前沿模型与研究 | → 模型前沿 + 研究与思想 | "GPT-6.2 灰测"和"陶哲轩随笔"本不该同栏 |
| 产品与行业 | → 安全与合规 + 商业与资本 + 工具箱快看 | 拆掉杂物间 |
| 社区脉搏（HN 列表） | → 并入各主题域 + 电报 | HN 是信源不是栏目；1731 分的故事该进头条而不是再列一遍 |
| GitHub 趋势榜 | → 开源雷达 | 增加老项目异动维度（dsh-prototype 13.1k 这种持续跟踪） |
| 今日头条/必读 | → 头条（唯一提级位）/ 必读（严格 1 条） | 头条不再与正文重复展开 |

## 五、补上的缺失维度（"我可能漏掉的"）

1. **安全与合规独立成节**——供应链攻击、 harness 条款收紧、出口管制，对做 agent 开发的人是 P0 信息，此前被稀释在 Coding 和"产品与行业"里。
2. **成本/定价视角**——agent 开发的单位经济学（Opus 5.5 降价 40%、Grok Bot 限流、Anthropic 内部用量超薪酬都是同一件事的不同面），用 💰 标记串起来。
3. **研究与思想独立**——论文和思想文本与产品新闻分家。
4. **已知项目跟踪**——不只报新项目，报"你在用的东西的重大变化"（版本、退役、迁移警告如 Opus 4.8 fast mode 11-30 退役）。
5. **国产动态标注 🇨🇳**——不设"中国专栏"（那会破坏主题域正交），但在各节内用标记保证不漏（DeepSeek 开源 harness、智元双模型、小米开源硬件这类）。
